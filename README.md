**Lumen Drift** is an original neon arcade space shooter, built for the [make.fun "Make the best game" bounty](https://make.fun/bounty/best-game-01). Fly with WASD or arrow keys, aim with the mouse, hold click or Space to fire. Blast waves of geometric enemies, chain combos up to ×8, collect star shards, grab power-ups (Spread, Shield, Overdrive), and chase the high score. Complete loop: title screen → waves → game over → restart (R). HUD shows score, best, combo, hull, wave, and power-up timers. All art is drawn in code and all sound is synthesized WebAudio. Vanilla JS + Canvas 2D, no libraries, no network requests, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `game/` with any static HTTP server and open `game/index.html`. Keyboard + mouse required.
